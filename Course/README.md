# Telecom Core Engineering Training Course

## 🧠 Overview

This course is a structured learning path for mastering:

- LTE / EPC Core Networks
- 5G Core (SA Architecture)
- GTP / Diameter / HTTP2 protocols
- DNS-based routing systems
- Charging systems (OCS / CHF)
- PFCP and user plane analysis
- Real-world troubleshooting (War Room level)

---

# 🎯 Course Philosophy

> “We don’t learn telecom as theory. We learn it as a living system.”

---

# 📚 Course Structure

## 🟢 Level 1 – Fundamentals
- LTE architecture
- Core network components
- Packet basics

## 🟡 Level 2 – EPC Core
- Attach procedure
- GTP-C / GTP-U
- Bearer setup
- PGW / SGW roles

## 🔵 Level 3 – Charging & Policy
- Diameter protocol
- OCS behavior
- PCRF rules
- Session control logic

## 🟣 Level 4 – 5G Core
- AMF / SMF / UPF roles
- SBA architecture
- HTTP/2 signaling
- NRF discovery

## 🔴 Level 5 – Advanced Troubleshooting
- PCAP analysis
- DNS routing issues
- PFCP failures
- War room incidents
