- LTE roaming architecture
- Steering of roaming (SoR)
- Data restriction scenarios in roaming

### 🔌 Protocols
- GTP-C / GTP-U
- Diameter (Gy, Gx, S6a)
- HTTP/2 (SBI in 5GC)
