# EPC Architecture Overview

## 🧠 LTE Core Network

```
UE
 │
eNB
 │
MME -------- HSS
 │
SGW -------- PGW -------- Internet
              │
           PCRF
              │
            OCS
```

---

## 🔍 Key Roles

- MME → Mobility & Control
- SGW → User plane anchor
- PGW → Internet gateway
- HSS → Subscriber database
- PCRF → Policy control
- OCS → Charging system
